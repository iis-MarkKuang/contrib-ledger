# Cross-chain

本次 demo 不跨链。贡献记录只上 Monad 测试网。不要加桥、消息通道或另一条链的部署，除非用户明确要求。

如果以后要做，先读官方目录 [Cross-Chain](https://docs.monad.xyz/tooling-and-infra/cross-chain.md)，再打开下面 Notion 给的入口。Lane 地址、endpoint 地址从那些文档现查，不要凭记忆写。
